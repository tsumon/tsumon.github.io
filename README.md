# 看得见的大模型

一本可交互的大语言模型图解书。从输入到办事，一条线走完注意力、预训练、微调、LoRA 和 Agent。

**阅读顺序：工程 → 数学 → 模型**（互动版与水墨本相同）。

互动版（可点滑块）：

- [工程基础](basics.html)（先读）
- [数学基础](math.html)
- [模型主线](index.html)

水墨本（讲故事、说人话，不点滑块）：

- [工程](ink-basics.html)（先读）
- [数学](ink-math.html)
- [模型](ink.html)

[start-here.html](start-here.html) 是数学 v2 的快速入口，不是全书封面。

本地打开可从 `basics.html` 起读（KaTeX 在 `vendor/katex`，不需要服务器或 CDN）。发布到 GitHub Pages 后，地址是：

`https://<username>.github.io/`（根目录仍是模型页；顶栏已按工程 → 数学 → 模型排列，也可直接打开 `/basics.html`）

互动版用 localStorage 键 `theme` 记深浅色。水墨本为宣纸静态页，无主题切换。旧 `doodle.html` 等地址会跳到对应水墨本。
